## Deploy to Cloudflare Workers

1. Install dependencies with `npm install`.
2. Authenticate with `npx wrangler login`.
3. Run `npm run deploy`.

To test locally, run `npm run dev`. The Worker forwards requests to `https://luminal.lol`.

- this is NOT source code, it's just a proxy so that anyone can deploy
- Static hosting is not supported; deploy with Cloudflare Workers.
